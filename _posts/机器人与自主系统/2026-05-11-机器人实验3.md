# 实验三

## 实验要求
自主移动机器人实验（三）—— Action 通信方式与接口设计

本实验实现：“机器人移动到指定目标点”的 Action 通信系统。

功能包括：
1.  Action Client 发送目标距离；
2.  Action Server 模拟机器人运动；
3.  实时反馈当前运动进度；
4.  到达目标后返回执行结果；
5.  支持取消任务。
